Multi-Source News Verification

MCP server for semantic search over Dominican news outlets. Point an MCP client at the streamable HTTP endpoint below.

MCP endpoint: /mcp

Auth header: Authorization: Bearer {{MCP_API_KEY}}

Tools

  • search_articles — semantic search across all articles (optional source / date window)
  • search_story — search stories and return matching stories with their articles
  • list_stories — compact browse of recent story clusters (description, sources, headlines)
  • get_story — full member articles for one story/cluster by STORY_ID
  • list_verified_articles — recent synthesized articles (status, confidence, title, slug)
  • get_verified_article — full verified body + sources + confidence by CLUSTER_ID
  • search_verified_articles — semantic search over verified title + body

Resources

  • news://sources — outlet catalog (JSON)
  • news://{source_id}/frontpage — last 1 day of articles for one outlet
  • news://verified/{cluster_id} — one synthesized (verified) article

Prompts

  • get_last_week — last 7 days of articles from a news outlet
